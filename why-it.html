WHY IT?

Why ICT suits me

I chose ICT because I have always been curious about technology and I like discovering how things work. I do not only want to use technology; I want to understand what happens behind it and learn how to create things myself.

I enjoy experimenting even when something does not work the first time. When I fix a problem myself, I understand the code better and feel motivated to try another challenge.

Why I chose the ICT programme at HZ

I like learning by doing, so practical assignments are important to me. Building this PCO portfolio at HZ has already given me a chance to practise HTML, CSS, Git and GitHub in a real project. I also value getting feedback from teachers and classmates because it helps me see what I can improve.

I want to continue studying programming and find out whether Software Engineering or Data Science fits my interests better. I think the HZ ICT programme can help me explore both through classes, projects and practice.

What I want to learn

  • Write cleaner code and understand why it works
  • Build useful programs with JavaScript and other languages
  • Learn how data and AI can solve practical problems
  • Improve my testing, teamwork and problem-solving skills

My long-term direction

In the future, I would like to work on software or AI projects that solve difficult problems. Space technology interests me because it combines software, data and science. I know I will need stronger programming, maths and teamwork skills before I can work in that field, so my first goal is to build a solid foundation.
