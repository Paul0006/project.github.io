Programming experience

My programming experience is still at the beginning. I have worked with HTML and CSS for this portfolio and I have started learning JavaScript. I use VS Code and Git/GitHub to work on my projects and save changes.

What I have learned

HTML gives a webpage its structure, while CSS controls how it looks. JavaScript lets me practise programming ideas such as functions, loops and arrays. Git helps me save different versions of my work, and GitHub lets me publish and share my website.

What was difficult?

Sometimes code does not work the way I expect. One thing I am learning is to check my code carefully, find the mistake, change it and test again instead of giving up. I also want to understand each line of code rather than only memorising what to type.

What is next?

I want to continue practising JavaScript and build small programs by myself. After that, I would like to try larger projects and learn how to organise my code better.
