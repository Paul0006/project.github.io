My direction in ICT

I do not want to decide too early that there is only one ICT job for me. I am interested in software development, AI, cybersecurity and technology connected to space. Two study directions that I want to understand better are Software Engineering and Data Science.

Software Engineering

Software Engineering is about designing, building, testing and maintaining software. A software engineer might work on websites, mobile applications or systems used by companies and researchers. Programmers also have to understand what users need and work together to fix problems.

For example, software engineers could develop a program that controls part of a satellite system or an application that shows scientific information. This interests me because I enjoy writing code and seeing something I built actually work.

Data Science

Data Science is about collecting, cleaning, analysing and understanding data. It often involves programming, statistics and visualising results. Data scientists look for patterns and can use machine learning to make predictions.

For example, a data scientist could study information collected from space observations or analyse large data sets to recognise patterns. This interests me because I like AI and the idea of using information to answer difficult questions.

Which direction suits me?

Right now I lean more towards Software Engineering because I like building programs and learning how code works. However, I also want to try more Data Science projects because AI and data are important in many areas of technology.

My plan is to strengthen my programming foundation, try projects in both directions and then make a better-informed choice based on what I enjoy doing in practice. In the long term, I would like to combine software skills with AI or space-related technology.
